# F1C200S LVGL Reader

Build: `make -C LVGL/reader -j2` from `/home/wnk/Desktop/F1c200S_SOFT`.
Uses existing GCC6.4 Buildroot sysroot, LVGL8 tree, menu platform/input code and streamed `cjk28.bin`. No SDL dependency.

Runtime: `/root/roms/candidates/reader_fullscreen_20261005/reader-app.sh`.
Menu launches file browser, browser exits before viewer, viewer exits before browser returns. Content uses the full480x800 screen, controls hidden initially. Swipe left advances, swipe right goes back; short center tap shows/hides overlay toolbar,10s idle hides it. Top-left exit and lower arrow buttons remain accessible after showing toolbar. Text top-right cycles encoding; image top-right switches Fit / 1:1 center-window. Toolbar visibility never resizes or rerenders content, it only overlays the page.

TXT: UTF8 with/without BOM, GBK, UTF16LE/BE BOM; invalid sequences become replacement glyphs. Reads4KiB source window per page.21 display lines/page,4096-page history; no full text cache. Manual encoding change resets to first page. No resume/bookmarks or arbitrary font-size control yet.
Images: JPEG,PNG,BMP,GIF(first frame only),TGA,PNM(binary PGM/PPM),PSD through upstream stb_image. Limits4096 per dimension,2M pixels,12MiB decoder allocation. Decoded source is freed after RGB565 screen-size conversion. Fit does not enlarge small images;1:1 clips a centered window (no pan yet). No animated GIF/WebP/HEIC/SVG image support.
Opening or switching to any image resets to proportional Fit, including after manually choosing1:1 for the previous image. Oversized images fit within the full480x800 screen, with no stretch. Different aspect ratios retain natural letterboxing; there is no toolbar-reserved region. Comic image folders are supported; zero-pad page filenames for the current lexicographic sort. CBZ/CBR archives are not supported.

Vendored `stb_image.h`: https://github.com/nothings/stb , MIT/public-domain dual license included at file end. Exact SHA256594c2fe35d49488b4382dbfaec8f98366defca819d916ac95becf3e75f4200b3. Not a newly hand-written image parser.
GBK map copied from tracked ONS generator output, SHA2568be7fbdd95c7535e65056fd1f3eb8ebf6dabe4fbf1c9dc09cd8628754b96fde0. Recreate with `python3 LVGL/ons_native/generate_gbk.py LVGL/reader/gbk_map.h`.
Reader punctuation font generated with `py -3 generate_reader_font.py` on Windows GDI/Microsoft YaHei; generated C is tracked for Linux builds. Original menu font/source unchanged.

Diagnostics default off: `READER_TEST_MS=3000` timed exit; `READER_SELFTEST=1` gesture/widget event tests; `READER_TEST_SHOW_UI=1` overlay screenshot preview; `READER_TEST_VISIBILITY_ONLY=1` stops selftest before navigation, with timed exit; `MEDIA_BROWSER_TEST_SELECT=filename` automatic browser selection; `READER_TEST_ONCE=1` launcher single selection. Normal menu sets none. CLI `reader --selftest-text`, `reader --selftest-gestures`, `reader --check-image path`, `reader-browser path --check/--list`.

PDF/EPUB: MuPDF1.24.9, full145MiB source and thirdparty tree vendored, AGPL3 licensing in vendor/COPYING and deployed COPYING.AGPL3. Combined document-reader source is available in this tracked repository; redistribution must comply with AGPL and thirdparty notices. No SDL, JavaScript/OCR/XPS or desktop viewer. Context allocation20MiB, store2MiB, render only current page to480x800 RGB then RGB565; release page/device/pixmap before next page. PDF original layout inFit mode (no PDF zoom/pan yet); EPUB reflows at24/28/32px through top-right button and uses MuPDF bookmarks to relocate after relayout. DRM/password-protected documents unsupported. Complex documents can hit budget and show an error; no blanket PDF compatibility/large-book memory claim.
Cross build `sh LVGL/reader/build-document-lib.sh`, then `make -C LVGL/reader -j2`; staticlibs in vendor/mupdf-1.24.9-source/build/f1-arm-small, all GCC6.4 with bundled FreeType/HarfBuzz/codecs and targetsystemJPEG/Zlib. No rootfs rebuild. Archive upstream SHA2560b446aa0eecc114e9969dccd70c9789358fccb6589a81d470dc941a0874da98a.
Generate fixtures with `python3 LVGL/reader/generate_document_samples.py` (stdlib only). Test `reader --check-document file` for first/last page checksums, then READER_SELFTEST=1 UI next/previous/reflow. Verified samplePDF3pages,ChineseEPUB15pages,IP5209 datasheet14pages. Residual306 allocator bytes observed after EPUB context close, reclaimed by process exit; do not represent EPUB internal teardown as zero or a long-session leak test. RSS samplesPDF5560KiB/EPUB8568KiB are for small fixtures only.

Tests recorded in WORKTREE_CHANGELOG.md. Menu integration and interactive candidate installed, not three-cold-boot stable acceptance.

Reader directory memory: launcher exports READER_PATH_STATE, default /root/roms/.reader-last-directory on SD. Browser atomically saves each successfully opened directory (same path skips write); next application launch restores that directory, not the last file or reading page. Missing/invalid/unavailable directory falls back to /root/roms. Explicit READER_START_DIR overrides remembered state. Save errors are nonfatal; optional READER_PATH_STATE can isolate tests. No per-frame memory writes.
Regression: run sh test-directory-memory.sh on board only after stopping the menu/app display owner. Uses isolated SD state, actual timed browser launches, cleanup trap. Restore menu service after test; does not modify normal remembered directory.
