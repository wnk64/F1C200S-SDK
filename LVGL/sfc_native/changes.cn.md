# 无 SDL SFC 模拟器

采用现存Retro-Go Snes9x轻量核心，上游32bb2913，47个核心文件与许可证已完整纳入Git b2ee8b2，核心不改。基线97ce5cd，不新增工作树。
新建独立LVGL/sfc_native，游戏画面直接写framebuffer，LVGL仅绘制控制与浏览器，不依赖SDL、不使用硬解或GPU。屏幕竖向480×800，游戏画面上部等比例适配，下面提供方向/A/B/X/Y/L/R/Start/Select及暂停/退出。
32kHz立体声走现有ALSA default，采用有界非阻塞队列；不更改蓝牙或耳机服务。键盘方向键，Z/X映射B/A，A/S映射Y/X，Q/W映射L/R，Enter/Tab映射Start/Select，Esc退出。板载触摸仍是单点，不能声称触摸同时按方向与动作键。
支持未压缩.sfc/.smc与目录选择，SRAM保存于同名.srm，不接入旧版不安全snapshot格式。前端ROM大小先做边界校验，但古老核心不能视为恶意ROM沙箱。
板子不在，先ARM构建、边界测试与自己编写的最小LoROM执行测试。不下载商业ROM，不宣称实机流畅或游戏兼容，三冷及实机显示/音频/输入待测。

## 离线构建结果

前端/浏览器/脚本/测试源码9b6a182，原Buildroot GCC6.4 ARMv5软浮点编译成功，无前端警告。readelf运行依赖只有asound、m、z、c，无SDL。
ASan/UBSan绘图测试验证RGB565转换、等比例区域、异常尺寸/stride、控制区和缓冲尾部不被越界写入。自写32KiB LoROM在qemu-arm-static运行120帧，119次帧内容变化、末帧57344非黑像素，重复hash42b6061d一致。ROM浏览器check/list及非法参数拒绝通过。
检查核心发现扫描线中途可以切512宽与交错模式，原历史前端只分256×239不够安全；新前端统一分配512×478×6字节连续区域，主/副屏与深度差值来自同一分配，不依赖不同malloc地址相减。仅约1.40MiB核心绘制区，不代表整进程实机RAM。
源码菜单第11项SFC入口已准备，原10项不改，无板端部署、不替换任何运行应用。应用退出前保存SRAM，浏览器与模拟器不同时持有界面；默认跳绘1帧，实际模拟速度未知。
ROM专用芯片/真实游戏兼容、实机显示方向/音频/触摸/键鼠、完整回归及三次冷启动均未完成。QEMU速度与有变化像素不等于板子实测播放。
