# 静态IP与菜单网络参数

用户要求静态IP并可菜单配置。基线统一根仓库634e3c8（原分支）；当前DHCP10.0.0.234/24、网关DNS10.0.0.1、Wi-Fi wnk641_2.4G、MAC04:4A:69:9D:1A:0E。使用当前地址，不修改路由器，需要在路由器排除DHCP池/保留地址避免未来冲突。

新增结构化f1-ip-config工具（配置不source进shell，IPv4/CIDR/同子网gateway校验），静态绑定当前SSID；其他SSID自动DHCP。原S17关联后先apply，仅返回2时回退DHCP；运行菜单切换停旧udhcpc，避免租约后续覆盖静态地址。设置Wi-Fi入口新增连接/IP设置二级页，静态开关/三项数值字段/数字键盘与应用按钮；SSH设置地址读实际值。不改内核、无线驱动、Wi-Fi凭据、蓝牙、投屏播放器。
