# 可关闭的播放器调试探针

正常入口 `launch-loop-with-menu.sh` 默认 F1_PLAYER_DEBUG=0、CEDAR_FRAME_GAP_STATS=0。不启动自动测试服务，不增加长期驻留探针进程。

`F1_PLAYER_DEBUG=1` 打开A/V主时钟差值和跨循环丢旧帧记录；`CEDAR_FRAME_GAP_STATS=1` 打开成功视频提交间隔日志。退出应用后，重新用默认入口启动即可关闭。错误及关键启停日志仍保留。

自动测试为单独的 `player-selftest`。它要求显式设置F1_PLAYER_DEBUG=1，输入为stdin的一条新HTTPS MP4地址（不把URL放诊断日志）。设置F1_CEDAR_PLAYER为专用候选、F1_CA_FILE为现有CA文件。测试时独占屏幕，先退出菜单/其他播放器，不对同时运行的投屏抢占显示。

自动测试内容：真实首帧、音量命令、两次暂停后seek195秒、每次跨过自然EOS后再次提交开头0～5秒及5.5秒以后帧、暂停1.2秒确认提交位置不变、恢复后确认位置前进。PASS表示这些软件/提交检查通过，不代替屏幕视觉、耳听同步或三次冷启动验收。

测试输入按TEST_PROTOCOL.md固定BV1GJ411x7h7获取新播放地址，不保存视频文件。总读取缓存512KiB有界，测试结果与退出码必须记录。失败后停止自有子进程，不无限后台重启。
